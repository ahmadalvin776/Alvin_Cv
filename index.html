Catatan belajar

5 Okt 2026

Memahami Flexbox lewat satu halaman portofolio

Web, 4 menit baca

Awalnya saya bingung kenapa elemen tidak mau sejajar. Ternyata saya lupa bahwa Flexbox bekerja pada elemen induk, bukan pada anak yang ingin diatur.

Setelah mencoba beberapa kali, saya mencatat tiga properti yang paling sering dipakai: display, justify-content, dan align-items.

22 Sep 2026

Normalisasi tanpa pusing: contoh dari data toko buku

Basis data, 6 menit baca

Normalisasi terasa abstrak sampai saya mencoba pada tabel penjualan yang berantakan. Memecah satu tabel besar menjadi tiga tabel kecil membuat data tidak lagi berulang.

Di tulisan ini saya tunjukkan tiap tahap dari 1NF sampai 3NF dengan contoh nyata.

10 Sep 2026

Apa yang saya pelajari dari kerja kelompok proyek web

Refleksi, 5 menit baca

Konflik kode di Git ternyata lebih mudah diselesaikan kalau tim sepakat pada aturan cabang sejak awal. Kami belajar itu dengan cara yang agak mahal.

Saya juga belajar bahwa menulis README yang jelas menghemat banyak pertanyaan di grup chat.

28 Agu 2026

Mengunggah situs pertama ke GitHub Pages

Web, 3 menit baca

Langkahnya ternyata singkat: buat repositori, unggah index.html, lalu aktifkan Pages di pengaturan. Situs saya tampil dalam beberapa menit.
